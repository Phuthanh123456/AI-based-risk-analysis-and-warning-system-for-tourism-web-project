# Existing application
React/Vite uses React Router, MUI, Leaflet, Framer Motion and Three.js. App and TravelPortal share public guides. TravelContext supplies authenticated trip inputs, API responses and map actions. FastAPI handles SQLite accounts/history, model inference, forecasts, news and route integration. The directory lists 34 current provinces with aliases to historical data. Existing journeyScene rendered a valley and birds. The discovery modal showed photographs only. The map selector and province circles were separate from the guide gallery. The baseline frontend suite passed 30 checks. The supplied recording and prior public-page captures informed the comparison; authenticated reference pages could not be fetched in this audit.
