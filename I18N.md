# Vietnamese and English interface

The VI / EN buttons are available in the site header and authentication layout,
including mobile. The choice is stored in `vtra_language`, synchronised between
tabs and applied to the HTML `lang` attribute and description metadata.

`travel-ui/src/i18n/en.json` contains the English interface and editorial guide
translations. `overrides.json` contains terminology and subsequent copy edits.
`translate.js` supports complete phrases and numbered interpolation slots.
Translations are bundled with the app: no visitor text, address or account data
is sent to an external translation service. React components translate display
values without modifying canonical place names, route IDs or coordinates.

All 90 catalog descriptions and their activity lists have English text. The
34-province directory supports English names and search. Food names such as
Phở, Bún bò Huế and Mì Quảng remain Vietnamese; distinctive cultural terms such
as Nhã nhạc and Đờn ca tài tử are retained with English context where appropriate.
Publisher article headlines and photo author names retain their original form;
the news interface and assessment explanations are translated.

Dates/numbers use `vi-VN` or `en-GB` formatting. The departure calendar still
uses the Vietnam time zone regardless of display language. Map labels are
supplied by the map provider and are not rewritten by the interface.

Address suggestion labels are translated for display. Selection retains the
original provider record and coordinates. `node scripts/audit-location-catalog.mjs`
regenerates the canonical region constraints and English-to-Vietnamese search
aliases. The backend maps recognised English place names to canonical lookup
queries, then applies the same source, coordinate and region checks.

Web Push payloads include English and Vietnamese wording; the service worker
uses the device's saved language preference. The preference cache contains only
the language, not pages, weather or map tiles.

Checks:

```text
npm --prefix travel-ui test
npm --prefix travel-ui run lint
npm --prefix travel-ui run build
python -m pytest tests/test_place_search.py tests/test_notifications.py -q
```

When adding visible text, supply an English dictionary entry and render it
through `useTranslate()`. Keep canonical data and API parameters unchanged.
