# Geographic outlines
The Vietnam miniature and the low-resolution map background use the country geometries from Natural Earth at 1:110 million scale. The original geometry coordinates are retained. Only features and properties were selected. These shapes provide regional context while street tiles load and have no role in routing, search or scoring.
